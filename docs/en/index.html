EXPLORE NIA_

Everything that belongs to the idea.

Built features, experimental capabilities and next steps, with their status in view. This page describes the development line; an older release may not include every addition.

In beta

A real terminal, built for Mac

SwiftUI and AppKit interface, Metal rendering and a Rust terminal core.

Details and scope

macOS 14+. ANSI colors, 256-color and truecolor capabilities, Unicode and an adaptive grid. Some TUIs, emoji and reflow cases still need full validation.

In beta

Sessions with an identity

Editable names, colors, search, drag ordering and independent history.

Details and scope

Stable identifiers, saved sessions and ⌘1–⌘9 shortcuts. Renaming does not change a session's identity or history.

Experimental

Split panes and multiple windows

Two terminals side by side or stacked, plus independent windows with ⌘N.

Details and scope

Each window remembers its layout. Within one process, a session is edited in one window to avoid conflicting resizes. Coordination across independent processes and complete window restoration remain incomplete.

In beta

Return to your context

Restore sessions, directory, history and a Python environment that is still installed.

Details and scope

Directory and venv capture uses Zsh hooks. The shell is recreated; terminated local processes are not restored and missing environments are not installed.

In beta

Memory on disk

Persistent ANSI output, configurable scrollback and an indexed history.

Details and scope

Scrolling preserves colors and rows up to the configured 1,000–100,000-line limit. Full output remains on disk; the text index cannot reconstruct a TUI pixel for pixel. Large logs can slow session opening.

In beta

Command timeline

Search commands, inspect duration and exit status, and return to their output.

Details and scope

Local Zsh captures directory, time, exit status and repetition count. Browse the latest 200 commands; copying or inserting does not execute them. Older commands without anchors cannot jump to their output.

In beta

Small gestures, less friction

Copy on selection, word, line or rectangular selection, and paths from Finder.

Details and scope

⌘C/⌘V, dropped files with shell-escaped paths and double Escape to clear a line with Emacs-style bindings. The native copy confirmation belongs to the new development line.

In beta

Links and quick insert

Open URLs with ⌘click and insert identifiers or passwords from the context menu.

Details and scope

HTTP/HTTPS links, copy link, UUID and password generators, plus legacy identifiers. Inserting text never sends Return. Some wrapped links are not recognized yet.

In beta

Close a session deliberately

Optional confirmation before closing a session with exit or logout.

Details and scope

Intercepts those exact commands at the local Zsh prompt. Cancel keeps the shell running; confirming preserves its history. It does not cover other shells, SSH or internal program exit commands.

In beta

An app that fits you

Light, dark or system appearance, with configurable font size and cursor.

Details and scope

Interface and settings in English and Spanish. Terminal opacity is experimental. Appearance changes do not alter sessions.

In beta

From natural language to a command

Type ? in local Zsh to receive an editable command suggestion.

Details and scope

Review and insert it. Optional automatic execution is restricted by a pattern validator, not a sandbox. The ? integration is not available in Bash, Fish or remote SSH.

In beta

Choose where AI runs

Optional internal model, local servers and external providers.

Details and scope

On-demand GGUF with llama.cpp; compatible endpoints such as Ollama, vLLM or LM Studio; OpenAI, Anthropic, Gemini and OpenRouter. Provider keys use Keychain. The internal model requires an additional download.

Experimental

Resume agent conversations

Remember explicit resume commands for Claude, Codex and Gemini.

Details and scope

Requires an ID in the original command, the CLI and conversation data on the Mac. Automatic discovery of IDs from conversations started without resume is still pending.

Experimental

Nia Remote

SSH + tmux to return to a shell living on another computer.

Details and scope

Uses your SSH configuration and verifies the host identity. The tmux session remains on the host while it stays running. Includes manual reconnection; it does not synchronize the workspace.

Experimental

Encrypted backups and handoff

Restic snapshots and manual recovery of state and history.

Details and scope

nia-backup and nia-handoff tools support local, SFTP or S3 repositories. Native UI configuration and execution, scheduling and guided restoration remain pending.

New · development

Five fonts for coding

JetBrains Mono, Fira Code, Cascadia Code, IBM Plex Mono and Source Code Pro.

Details and scope

Optional licensed, verified downloads registered only for nia_. Select without restarting. The cell renderer does not enable multi-character ligatures. Implemented in the development build.

New · development

Claude and Codex quotas in view

An optional bar with weekly usage, resets and token counts labeled by scope.

Details and scope

Codex reads its local CLI. Claude needs its status-line adapter connected and a response emitted. Data depends on the plan; unavailable quota is not displayed as zero. Implemented in development.

New · development

Updates from GitHub

Version checks, stable or prerelease channels, and confirmed download and installation.

Details and scope

Checks integrity and compatibility before replacing the app. Uses the gh session if the repository needs private access. Development additions may not yet be published in a release.

An actions.toml format and historical code exist. Native SwiftUI integration, session targeting and confirmation remain pending. It is not currently available as a native app feature.

FROM ONE MAC TO ANOTHER

Pick up where you left off.
That is the destination.

There are three different needs behind that idea. Today, there are foundations for reconnecting and transferring; automatic workspace synchronization is still to come.

Today · experimental

Return to the same process

SSH + tmux lets you connect from another Mac to a shell still running on the remote computer. That host must remain available. The process does not move between computers.

Today · manual

Take saved state with you

Encrypted backups and manual handoff can restore metadata and history on another Mac. Projects, paths and environments need to exist there. Live processes are not transferred.

Nia Sync · planned

Share a workspace across both

Pair Macs, synchronize encrypted changes, resolve conflicts and choose where to continue. This is part of the vision for nia_, but automatic two-way sync is not implemented yet.

A BETA IN MOTION

What is built is the beginning.

The direction is clear. Priorities may change with real-world use and testing; these are not delivery dates.

Technical status and remaining work

Strengthen everyday use

Refine scrolling, reflow, focus, fullscreen applications and multi-window restoration. Measure performance and expand accessibility checks.

Complete the recovery experience

Configure, schedule and restore backups from the app, and verify recovery on another Mac. Improve retention and control over what is recorded.

Build Nia Sync

Device identities, pairing, recoverable keys, a change journal, incremental transfer and rules for conflicts and deletions.

Extend continuity

Explore a persistent session service, automatically discover agent conversations and improve reconnection. Expand shell integration beyond Zsh.

Before you open the beta.

Can I automatically sync two Macs today?

Not yet. You can reconnect to a remote session with SSH + tmux or manually transfer an encrypted backup. Nia Sync remains on the roadmap.

Do my processes survive quitting nia_?

Local shells are recreated when the app opens: saved state returns, not process memory. A remote tmux session can remain alive on its host while that host continues to run.

Do I have to use AI?

No. Assistance is optional. Choose local inference or an external provider; an external provider receives the queries you send to it. A model's suggestion can be wrong and needs review.

Where is my history stored?

On your Mac. Restic backups are encrypted before storage in your configured backup repository. Local history may contain sensitive data; comprehensive retention and redaction controls are still pending.

What do I need to try it?

macOS 14 or later. Check available releases and their requirements. Repository and download access may be limited during this phase; development may be ahead of the latest release. Distribution is not yet notarized by Apple.

How can I help it evolve?

Share reproducible bugs, proposals and experiences on GitHub when you have repository access. The code uses MPL-2.0; dependencies and models have their own licenses.
