# Nia v0.5.8 — Controlled AI actions

- Optional automatic execution of a tightly allowlisted single command generated by AI.
- Allows simple read-only commands (`find`, `ls`, `du`, `df`, `pwd`, `whoami`, `date`, `uptime`).
- Allows `python3 -m http.server` on ports 1024–65535, forced to `127.0.0.1`.
- Blocks pipelines, redirects, shell substitutions, quoting, command chaining, dangerous `find` predicates and unknown commands from automatic execution.
- Unapproved commands still appear as editable proposals and are never run without user confirmation.
- Automatic execution requires the originating terminal still be selected and focused.
- Toggle in Preferences → IA. Auto execution does not extend to SSH or non-Zsh input interception.
- No static classifier is a security sandbox: shell aliases and filesystem contents may still be surprising. Review if in doubt.
